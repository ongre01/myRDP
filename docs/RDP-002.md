# RDP-002 FreeRDP Client Wrapper

## 구현 결과

`RdpClient`는 Qt 애플리케이션 계층과 FreeRDP Client API 사이에서 다음 책임을 담당한다.

- 생성 시 `freerdp` 인스턴스와 컨텍스트 초기화
- 서버 주소 및 포트 유효성 검사와 FreeRDP 설정 적용
- 연결 및 연결 종료 요청 전달
- 현재 초기화/연결 상태와 마지막 오류 제공
- Application Layer가 FreeRDP 헤더를 포함하지 않고 라이브러리 버전을 조회할 수 있는 정적 API 제공
- 소멸 시 연결 종료, 컨텍스트 해제, 인스턴스 해제를 순서대로 수행

공개 헤더는 FreeRDP 헤더나 내부 객체를 노출하지 않는다. FreeRDP 타입과 API 호출은 PIMPL 구현인 `rdpclient.cpp` 안에만 존재하므로 UI와 Application Layer는 `ConnectionInfo` 및 `RdpClient` 인터페이스만 사용한다.

## 공개 인터페이스

```cpp
struct ConnectionInfo
{
    QString serverAddress;
    int port = 3389;
};

class RdpClient
{
public:
    bool connectToServer(const ConnectionInfo &info);
    void disconnect();

    bool isInitialized() const;
    bool isConnected() const;
    QString lastError() const;
    static QString libraryVersion();
};
```

`connectToServer()`는 초기화 실패, 잘못된 주소/포트, FreeRDP 설정 실패 또는 FreeRDP 연결 실패 시 `false`를 반환한다. 상세 원인은 `lastError()`로 확인한다. 생성 직후 `isInitialized()`를 확인하면 인스턴스나 컨텍스트 초기화 실패도 Application Layer에서 처리할 수 있다.

## 리소스 수명 주기

```text
RdpClient 생성
  -> freerdp_new
  -> freerdp_context_new

RdpClient 소멸
  -> freerdp_disconnect (연결된 경우)
  -> freerdp_context_free
  -> freerdp_free
```

복사와 이동은 금지하여 하나의 FreeRDP 인스턴스에 소유자가 둘 이상 생기지 않도록 했다. `disconnect()`는 연결되지 않은 상태에서도 안전하게 호출할 수 있다.

## 현재 범위

이번 구현은 Wrapper의 생성/해제와 기본 연결 요청 경계를 제공한다. 사용자 인증, 인증서 확인, FreeRDP 이벤트 처리, Framebuffer 및 Qt 화면 출력은 후속 티켓에서 이 Wrapper 내부 구현을 확장해 추가한다.
