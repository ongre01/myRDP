# RDP-014 자체 Client ↔ Server 통합 검증

## 구현 결과

자체 `RdpClient`와 `RdpServer`를 loopback RDP/TLS 연결로 함께 실행하는 통합 테스트를
추가했다. 이 테스트는 연결과 인증서 판단부터 화면, 입력, clipboard, 종료, 같은 client
instance의 재연결까지 한 흐름으로 검증한다.

```text
RdpClient
    |
    | RDP/TLS + cliprdr
    v
RdpServerSession
    |-- IntegrationDesktopCapture
    |-- IntegrationInputController
    `-- IntegrationClipboardController
```

Network protocol과 FreeRDP client/server stack은 실제 구현을 사용한다. 자동 테스트가 개발자
PC의 화면, 입력 장치, system clipboard를 변경하지 않도록 Server의 platform adapter만
thread-safe test double로 주입한다. 기본 `RdpServer` 생성자는 기존과 같이 실제 platform
factory를 사용한다.

## 통합 과정에서 보완한 사항

- Client가 Server의 NSCodec bitmap update를 협상하도록 `FreeRDP_NSCodec`을 활성화했다.
- Server 초기화 시 FreeRDP server WTS API function table을 등록했다.
- `cliprdr` channel join이 끝난 `Activate` 시점에 virtual channel manager와 clipboard
  context를 생성한다.
- Session worker가 virtual channel manager event를 함께 처리해 clipboard 초기화 및 데이터
  PDU를 transport로 내보내도록 했다.
- Client disconnect 시 GDI update callback을 해제해 같은 `RdpClient` instance의 재연결 전에
  이전 framebuffer callback이 호출되지 않도록 했다.
- `RdpServerDependencies`를 추가해 capture, input, clipboard platform factory를 통합 테스트에
  안전하게 주입할 수 있게 했다.

## 자동 검증 범위

`RDPServer/tests/tst_rdpserver.cpp`의 `integratesOwnClientAndServer()`는 다음 순서로 검증한다.

1. 동적 loopback port에서 자체 Server를 시작한다.
2. 자체 Client의 인증서 callback에서 self-signed 인증서를 거부하고, 연결 실패와 fingerprint
   전달을 확인한다.
3. `TrustOnce`로 연결하고 640×480 초기 frame 및 16×16 dirty refresh를 확인한다.
4. scan code, pointer 이동, 좌측 button press/release, 음수 wheel delta가 Server input
   controller까지 전달되는지 확인한다.
5. 한글과 줄바꿈이 포함된 Unicode text를 Client → Server 및 Server → Client 양방향으로
   전송한다.
6. 연결 종료 후 Server session이 제거되는지 확인한다.
7. 같은 Client instance로 재연결해 화면 갱신과 clipboard 전송을 다시 확인한다.

여기서 인증 검증은 현재 제품 범위인 TLS server certificate의 명시적 거부/일회성 신뢰
결정이다. Username/password 정책이나 NLA 사용자 인증은 이 ticket의 범위가 아니다.

## 검증 결과

Qt 6.11.0 MSVC 2022 64-bit와 저장소의 FreeRDP build를 사용해 다음을 확인했다.

- Debug `RdpServerTest`: 12 passed, 0 failed
- Release `RdpServerTest`: 12 passed, 0 failed
- Debug `RdpClientChannelTest`: 3 passed, 0 failed
- 최상위 Client/Server Debug build 성공
- 최상위 Client/Server Release build 성공
- Debug/Release Client/Server 실행 파일 4개의 offscreen startup smoke test 통과

Build 중 출력되는 warning은 FreeRDP/WinPR public header의 기존 deprecated 선언이다. 자동
통합 테스트는 실제 Windows desktop/input/system clipboard 대신 adapter test double을
사용하므로, 실제 장치와의 수동 GUI 조작 검증을 대체하지는 않는다.
