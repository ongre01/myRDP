# RDP-005 Remote Desktop 화면 출력 구현

## 구현 결과

`RDPClient`가 FreeRDP의 software GDI framebuffer를 Qt 전용 Widget에 표시하도록
화면 수신 및 렌더링 경로를 구현했다.

- 연결 완료 시 BGRA32 software GDI framebuffer 초기화
- FreeRDP `BeginPaint`, `EndPaint`, `DesktopResize` callback 처리
- 16ms Qt timer에서 FreeRDP event handle 처리
- 변경 영역만 framebuffer에서 독립된 메모리로 복사
- 원격 해상도와 dirty rectangle을 UI 계층에 전달
- 클라이언트 창 크기에 맞춘 종횡비 유지 렌더링
- 원격 해상도 변경 시 framebuffer와 Qt image 재생성
- 수동 종료, 원격 종료, 연결 실패 시 화면 및 GDI 자원 정리

## 구성

화면 데이터 처리와 Qt 렌더링은 다음과 같이 분리한다.

```text
FreeRDP update callback
  |
  | BGRA32 framebuffer + invalid region
  v
RdpClient
  |
  | DesktopUpdate (desktop size, dirty rect, copied pixels)
  v
MainWindow
  |
  | QImage view of the copied region
  v
RemoteDesktopWidget
  |
  v
Qt paintEvent
```

`RdpClient`는 FreeRDP framebuffer의 수명과 protocol event 처리를 담당한다.
`RemoteDesktopWidget`은 FreeRDP API를 알지 못하며 전달받은 영역을 내부 `QImage`에
반영하고 화면에 그리는 역할만 담당한다.

## Framebuffer와 변경 영역 처리

`PostConnect`에서 `gdi_init(..., PIXEL_FORMAT_BGRA32)`를 호출하고 FreeRDP의
software GDI를 활성화한다. `BeginPaint`에서는 이전 invalid region을 초기화하고,
`EndPaint`에서는 이번 frame의 invalid bounding rectangle을 desktop 범위로 제한한
뒤 해당 BGRA32 행만 복사한다.

`DesktopUpdate`는 다음 정보를 UI에 전달한다.

- 전체 원격 Desktop 크기
- 변경된 Desktop 좌표 영역
- 변경 영역의 독립된 pixel buffer
- pixel buffer의 bytes-per-line

FreeRDP가 소유한 framebuffer pointer를 Qt가 보관하지 않기 때문에 다음 protocol
update나 연결 종료 후에도 UI가 해제된 메모리를 참조하지 않는다.

## 화면 갱신과 창 크기 변경

연결 성공 후 `MainWindow`의 precise timer가 16ms 간격으로
`freerdp_check_event_handles()`를 호출한다. 이 처리가 새로운 RDP frame을 decode하고
등록된 paint callback을 실행한다.

`RemoteDesktopWidget`은 원격 Desktop과 같은 크기의 `QImage`를 유지한다. 수신한
dirty rectangle만 image에 복사하고, 해당 영역을 현재 Widget 좌표로 변환해 repaint를
요청한다. Widget의 `paintEvent`는 원격 화면의 종횡비를 유지하면서 사용 가능한
영역에 맞추므로 Client Window 크기가 바뀌어도 화면이 잘리거나 비율이 왜곡되지
않는다. 남는 영역은 어두운 배경으로 표시한다.

FreeRDP가 `DesktopResize`를 알리면 GDI framebuffer를 협상된 새 해상도로 변경하고
전체 영역 update를 전달한다. Qt image도 새 Desktop 크기로 다시 생성된다.

## 종료 및 오류 처리

수동 연결 종료 전에 event timer를 중지하고 `freerdp_disconnect()`를 호출한다.
FreeRDP의 `PostDisconnect` callback은 `gdi_free()`로 framebuffer를 해제한다.
`RdpClient` 소멸 시에도 같은 종료 순서를 수행한다.

원격 종료나 event 처리 오류가 발생하면 연결 상태를 종료하고 UI의 Desktop image를
비운 뒤 오류 상태를 표시한다. 재연결을 시작할 때도 이전 연결의 image를 먼저
제거한다.

## 검증

Qt 6.11.0 MSVC 2022 64-bit와 repository의 FreeRDP build를 사용해 다음을 확인했다.

- Debug 빌드 성공
- Release 빌드 성공
- Debug 실행 파일 offscreen startup smoke test 성공
- Release 실행 파일 offscreen startup smoke test 성공
- `RemoteDesktopWidget` dirty-region, 종횡비 유지, Window resize, clear 동작의
  offscreen rendering test 성공
- `git diff --check` 통과

빌드 중 FreeRDP/WinPR public header의 deprecated type/callback warning이 출력되지만
이번 구현에서 추가한 컴파일 오류나 warning은 없다.

실제 Windows Remote Desktop 화면 수신은 접속 가능한 서버 자격 증명과 대화형
세션이 필요하므로 이번 자동 검증에서는 수행하지 않았다.
