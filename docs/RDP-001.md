# RDP-001 프로젝트 기본 구조

## 구현 결과

QtRdp는 다음 구조로 구성된다.

```text
QtRdp/
├── FreeRDP/                 # Git submodule
├── qmake/
│   └── freerdp.pri          # 공통 FreeRDP include/link 설정
├── RDPClient/               # 독립 Qt Widgets 애플리케이션
├── RDPServer/               # 독립 Qt Widgets 애플리케이션
├── docs/
└── QtRdp.pro                # 전체 빌드용 qmake SUBDIRS 프로젝트
```

`RDPClient`와 `RDPServer`는 각각 독립 실행 파일이며, 루트의 `QtRdp.pro`로 두 프로젝트를 순서대로 함께 빌드할 수도 있다. 두 애플리케이션은 시작할 때 `freerdp_get_version_string()`을 호출하므로 FreeRDP 헤더뿐 아니라 라이브러리 링크도 빌드 시 검증된다.

## 소스 받기

새로 복제할 때는 서브모듈을 함께 받는다.

```powershell
git clone --recurse-submodules <repository-url> QtRdp
cd QtRdp
```

이미 저장소를 복제했다면 다음 명령으로 FreeRDP 서브모듈을 초기화한다.

```powershell
git submodule update --init --recursive
```

## FreeRDP 빌드 및 설치

qmake 프로젝트는 FreeRDP 소스 트리를 직접 참조하지 않는다. FreeRDP 빌드 과정에서 생성되는 `freerdp/config.h`와 `winpr/config.h`가 필요하므로, CMake 설치 트리를 참조한다.

Windows용 기본 설치 위치는 저장소의 `build/freerdp-install`이다. Visual Studio 2022 x64, CMake 및 vcpkg가 설치된 환경에서 제공 스크립트를 실행한다. 스크립트는 `vcpkg.json`에 선언된 OpenSSL을 준비하고 RDP-001에 필요한 최소 FreeRDP 공유 라이브러리를 빌드한다.

```powershell
.\scripts\build-freerdp.ps1
```

vcpkg가 자동 감지되지 않으면 설치 루트를 지정한다.

```powershell
.\scripts\build-freerdp.ps1 -VcpkgRoot 'C:\path\to\vcpkg'
```

설치 결과에는 최소한 다음 파일이 있어야 한다.

```text
build/freerdp-install/
├── include/freerdp3/freerdp/freerdp.h
├── include/winpr3/winpr/winpr.h
├── lib/freerdp3.lib
├── lib/freerdp-client3.lib
├── lib/freerdp-server3.lib
└── lib/winpr3.lib
```

다른 위치에 설치했다면 qmake 실행 전에 `FREERDP_INSTALL_PREFIX` 환경 변수를 설정한다.

```powershell
$env:FREERDP_INSTALL_PREFIX = 'D:\Libraries\FreeRDP'
```

API 주 버전이 3이 아닌 FreeRDP를 사용할 때는 qmake 변수 `FREERDP_API_VERSION`도 지정해야 한다.

Qt Creator가 열려 있었다면 FreeRDP 설치 후 `Build > Run qmake`를 실행한다. 이전 구성 오류가 남아 있으면 현재 Kit의 빌드 디렉터리를 정리한 뒤 qmake를 다시 실행한다.

## QtRdp 빌드

Qt 6 MSVC 2022 64-bit Developer PowerShell에서 전체 프로젝트를 빌드한다.

```powershell
New-Item -ItemType Directory -Force build/qt-release | Out-Null
Push-Location build/qt-release
qmake ../../QtRdp.pro CONFIG+=release
nmake
Pop-Location
```

각 애플리케이션은 독립적으로도 구성할 수 있다.

```powershell
qmake RDPClient/RDPClient.pro CONFIG+=release
qmake RDPServer/RDPServer.pro CONFIG+=release
```

실행 시 FreeRDP DLL을 찾을 수 있도록 설치 디렉터리의 `bin`을 `PATH`에 추가한다. Qt DLL 배포에는 Qt의 `windeployqt`를 사용한다.

```powershell
$env:PATH = "$PWD\build\freerdp-install\bin;$env:PATH"
```

## qmake 연동 규칙

- `RDPClient`는 `freerdp-client3`, `freerdp3`, `winpr3`를 링크한다.
- `RDPServer`는 `freerdp-server3`, `freerdp3`, `winpr3`를 링크한다.
- 필요한 헤더나 Windows import library가 없으면 qmake 구성 단계에서 해당 경로를 포함한 오류를 출력한다.
- FreeRDP 설치 경로와 API 주 버전은 각각 `FREERDP_INSTALL_PREFIX`, `FREERDP_API_VERSION`으로 재정의할 수 있다.
