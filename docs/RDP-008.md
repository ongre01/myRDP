# RDP-008 FreeRDP Server 최소 구조

## 구현 결과

`RDPServer`에 Qt UI와 FreeRDP server API 사이의 `RdpServer` wrapper를 추가했다.
wrapper는 FreeRDP 타입을 공개 헤더에 노출하지 않으며 listener 생성, 지정 endpoint의
listen, peer accept, session 소유, 종료 처리를 담당한다.

```text
MainWindow
  |
  | RdpServerConfiguration / Qt signals
  v
RdpServer
  |
  | freerdp_listener
  v
FreeRDP server listener
```

UI에서 bind address와 port를 지정한 후 서버를 시작하거나 중지할 수 있다. 기본값은
`0.0.0.0:3389`이다. 상태, 활성 session 수, 연결/종료 이벤트는 창의 event log에
표시된다.

## Session 구조

수락한 `freerdp_peer`마다 별도의 `RdpServerSession` 객체와 worker thread를 만든다.
`RdpServer`는 session을 ID별 collection으로 소유하므로 이후 복수 client 기능을
확장할 수 있다.

```text
RdpServer
  +-- RdpServerSession 1 -> freerdp_peer 1
  +-- RdpServerSession 2 -> freerdp_peer 2
  +-- ...
```

이번 티켓의 session은 아직 RDP protocol 처리를 시작하지 않으며, socket에 도착한
data를 읽어 버리면서 client disconnect를 감지한다. 다음 티켓에서는 이 임시 감시
loop를 FreeRDP peer 초기화와 protocol event loop로 교체해 frame 전송을 추가한다.
인증서, protocol negotiation, 화면 전송은 RDP-009 이후 범위이며 이번 구현에는
포함하지 않는다.

## 수명주기와 thread 정리

- `RdpServer` 생성 시 `freerdp_listener`와 stop event를 준비한다.
- `start()`가 endpoint를 검증하고 FreeRDP listener를 연 뒤 listener worker를 시작한다.
- FreeRDP `PeerAccepted` callback이 session을 생성하고 peer 소유권을 넘긴다.
- session worker가 원격 socket 종료를 감지하면 `clientDisconnected` signal을 보낸다.
- listener worker는 종료된 session을 join한 뒤 collection에서 제거한다.
- `stop()`은 신규 accept를 막고 listener와 모든 session worker를 깨운 뒤 join한다.
- 모든 worker가 끝난 후 listener, peer, WinPR handle을 해제한다.

이 순서로 UI 종료 중 callback이 이미 해제된 객체를 참조하거나 worker thread가 남는
문제를 방지한다. 서버는 중지 후 같은 wrapper instance에서 다시 시작할 수 있다.

## 검증

`RDPServer/tests/tst_rdpserver.cpp`는 다음을 자동 검증한다.

- port 0 설정 거부와 오류 제공
- loopback 임시 port listen
- 실제 TCP client 연결에 따른 `clientConnected` signal과 session 생성
- client가 data를 보낸 뒤 socket을 종료해도 `clientDisconnected` signal과 session 제거
- `stop()` 후 listening 상태 해제
- 같은 wrapper instance에서 stop 후 재시작

실제 RDP negotiation과 화면 표시 검증은 test frame 전송을 구현하는 RDP-009에서
수행한다.

Qt 6.11.0 MSVC 2022 64-bit와 저장소의 FreeRDP build를 사용해 다음을 확인했다.

- Debug 빌드 성공
- Release 빌드 성공
- `RdpServerTest` 4개 case 통과(init/cleanup 포함)
- Release 실행 파일 offscreen startup smoke test 통과

빌드 출력의 warning은 FreeRDP/WinPR public header에 있는 기존 deprecated 선언이며,
이번 구현 코드에서 추가된 warning이나 error는 없다.
