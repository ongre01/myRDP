# RDP-012 Server 원격 Keyboard / Mouse 입력 처리

## 구현 결과

RDP Server session이 FreeRDP의 입력 callback을 등록하고, 수신한 RDP 입력을 Windows
로컬 입력으로 전달하도록 구현했다. Application Layer는 Windows API를 직접 사용하지 않고
`InputController` 인터페이스에만 의존한다.

```text
RDP Client
    |
    | KeyboardEvent / UnicodeKeyboardEvent
    | MouseEvent / RelMouseEvent / ExtendedMouseEvent
    v
RdpServerSession callback
    |
    v
RdpInputHandler -- RDP flag 해석 --> 의미 기반 입력
    |
    v
InputController
    |
    v
WindowsInputController -- INPUT / SendInput --> Windows desktop
```

`createInputController()`는 Windows build에서 `WindowsInputController`를 생성한다. 따라서
향후 macOS 입력 구현을 추가할 때 FreeRDP callback과 flag 해석 코드는 유지하고 platform
factory 분기만 확장할 수 있다.

## FreeRDP 입력 변환

`RdpInputHandler`가 FreeRDP protocol flag를 platform-independent 입력으로 변환한다.

| FreeRDP 입력 | 변환 결과 |
| --- | --- |
| Scan code keyboard | scan code, press/release, extended key |
| Unicode keyboard | UTF-16 code unit, press/release |
| Absolute mouse move | desktop 기준 `x`, `y` |
| Relative mouse move | signed `deltaX`, `deltaY` |
| Button 1/2/3 | left/right/middle press 또는 release |
| Extended button 1/2 | X1/X2 press 또는 release |
| Wheel/HWheel | vertical/horizontal signed wheel delta |

음수 wheel 값은 RDP의 sign flag와 하위 8-bit 보수 값을 해석해 Windows의 signed delta로
변환한다. 하나의 pointer event에 move와 button flag가 함께 있으면 이동을 먼저 적용한 뒤
button 상태를 적용한다.

Session 초기화 시 다음 FreeRDP 입력 callback을 연결한다.

- `KeyboardEvent`
- `UnicodeKeyboardEvent`
- `MouseEvent`
- `RelMouseEvent`
- `ExtendedMouseEvent`

Horizontal wheel, extended mouse button, relative mouse capability도 server settings에
활성화했다.

## Windows 입력 적용

`WindowsInputController`는 Win32 `INPUT` 구조체를 구성하고 `SendInput`으로 주입한다.

- Keyboard scan code는 `KEYEVENTF_SCANCODE`를 사용한다.
- Key release는 `KEYEVENTF_KEYUP`, extended key는 `KEYEVENTF_EXTENDEDKEY`를 추가한다.
- Unicode 입력은 `KEYEVENTF_UNICODE`를 사용한다.
- 절대 pointer 좌표는 Windows virtual desktop 크기를 기준으로 `0..65535` 범위로
  정규화한다.
- Absolute move에 `MOUSEEVENTF_VIRTUALDESK`를 사용하므로 primary monitor뿐 아니라
  RDP-011에서 capture하는 전체 virtual desktop과 좌표계가 일치한다.
- Left/right/middle/X1/X2 button과 vertical/horizontal wheel을 각각 해당 Win32 flag로
  변환한다.

좌표가 virtual desktop 범위를 벗어나면 마지막 pixel로 제한한다. Windows가 유효한 virtual
desktop 크기를 반환하지 않거나 `SendInput`이 입력을 주입하지 못하면 상세 오류를 session에
반환한다. Session은 기존 `RdpServer` 오류 경로를 통해 첫 입력 오류를 `lastError()`와
`errorOccurred` signal에 전달하고 연결 처리를 실패시킨다.

Windows 보안 정책상 `SendInput`은 UIPI 무결성 수준과 실행 session의 영향을 받는다. 따라서
Server가 다른 사용자 session 또는 더 높은 무결성 수준의 process를 제어해야 하는 배포
구성에서는 별도의 service/session 연동 설계가 필요하다. 현재 구현은 로그인한 사용자와 같은
interactive desktop에서 실행되는 Server를 대상으로 한다.

## 자동 검증

`RDPServer/tests/tst_rdpserver.cpp`에 실제 사용자 입력을 발생시키지 않는 검증을 추가했다.

- Scan code key press/release 및 extended key 변환
- Unicode key 변환
- Absolute/relative mouse move 변환
- Left/right/middle/X1/X2 button 변환
- Positive/negative vertical/horizontal wheel 변환
- Platform controller 오류의 session용 메시지 변환
- Win32 `INPUT` keyboard/mouse flag와 virtual desktop 좌표 정규화
- `SendInput` 실패 시 Windows error 전달
- Platform factory 생성

Windows controller test는 주입 가능한 `InputSender`와 system metric reader를 사용한다. 이
때문에 test 실행 중 실제 keyboard 입력이나 pointer 이동이 발생하지 않는다.

## 검증 결과

Qt 6.11.0 MSVC 2022 64-bit와 저장소의 FreeRDP build를 사용해 다음을 확인했다.

- RDPServer Debug build 성공
- RDPServer Release build 성공
- Debug `RdpServerTest`: 9 passed, 0 failed
- Release `RdpServerTest`: 9 passed, 0 failed
- Debug/Release 실행 파일 offscreen startup smoke test 통과
- 기존 TLS client desktop frame 수신 및 재연결 test 통과

Build warning은 FreeRDP/WinPR public header의 기존 deprecated 선언이다. 실제 외부 RDP
Client를 이용한 keyboard/mouse 수동 조작과 권한 수준이 다른 process에 대한 입력 주입은 이번
자동 검증에 포함하지 않았다.
