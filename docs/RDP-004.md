# RDP-004 Windows 기본 RDP Server 연결

## 구현 결과

`RDPClient`가 FreeRDP 3 API를 사용해 Windows Remote Desktop Server와 연결을
협상하고 사용자 자격 증명으로 인증할 수 있도록 연결 계층을 확장했다.

- Server address와 Port를 FreeRDP 설정에 전달
- User name, Password, 선택적 Domain을 NLA/CredSSP 인증 설정에 전달
- FreeRDP의 기본 NLA, TLS, RDP 보안 계층 협상을 활성화
- 알 수 없거나 변경된 서버 인증서를 사용자가 확인한 뒤 현재 연결에만 신뢰
- DNS, 전송, 인증 실패를 구분한 사용자 오류 메시지 제공
- 연결 성공 상태 추적과 `freerdp_disconnect()`를 통한 정상 종료

## 연결 흐름

```text
MainWindow
  |  주소, 포트, 자격 증명
  v
RdpClient::connectToServer
  |  FreeRDP settings + certificate callbacks
  v
freerdp_connect
  |  Security negotiation / TLS / NLA(CredSSP)
  v
Windows Remote Desktop Server
```

`ConnectionInfo`는 연결 대상과 자격 증명 외에 인증서 확인 콜백을 전달한다.
FreeRDP가 신뢰되지 않은 인증서 또는 이전과 달라진 인증서를 보고하면 Wrapper가
인증서 정보를 Qt UI에 전달한다. 사용자가 `Trust for this connection`을 선택한
경우에만 FreeRDP의 세션 한정 승인 값인 `2`를 반환한다. 인증서는 무조건
허용하거나 영구 저장하지 않는다.

## 인증 및 오류 처리

User name은 필수이며 Password는 FreeRDP에 빈 문자열까지 명시적으로 전달한다.
Domain은 로컬 계정 접속을 위해 비워 둘 수 있다. 자격 증명은 설정 파일 등에
저장하지 않는다.

연결 실패 시 FreeRDP의 last-error 코드, 이름, 설명을 사용한다. 인증 관련 오류는
계정·비밀번호·Domain·Remote Desktop 권한을 확인하도록 안내하고, DNS 오류와
전송 연결 오류는 서버 주소 및 도달 가능성 문제로 구분한다. 사용자가 인증서를
거부한 경우에는 별도 인증서 거부 오류를 표시한다.

Disconnect는 활성 연결에서만 실행하며, 종료 결과와 내부 연결 상태를 함께
갱신한다. `RdpClient` 소멸 시에도 활성 연결을 종료한 다음 FreeRDP context와
instance를 해제한다.

## 범위

이 티켓은 연결 협상, 인증, 실패 및 종료 처리까지 구현한다. 연결 이후 RDP 이벤트
처리와 Framebuffer 렌더링은 RDP-005 범위다.
