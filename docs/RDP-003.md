# RDP-003 Windows RDP Client 최소 UI

## 구현 결과

`RDPClient`의 기본 창에 다음 연결 및 상태 확인 UI를 추가했다.

- 호스트 이름 또는 IP 주소를 입력하는 Server address 필드
- `1`부터 `65535`까지 입력할 수 있고 기본값이 `3389`인 Port 필드
- Connect 및 Disconnect 버튼
- Disconnected, Connecting, Connected, Connection failed 상태 표시
- 연결 오류를 표시하는 대화상자와 상태 표시줄
- 후속 화면 출력 구현이 사용할 `remoteDesktopView` 영역

## Wrapper 연동

Connect를 누르면 UI의 주소와 포트로 `ConnectionInfo`를 만들고
`RdpClient::connectToServer()`에 전달한다. 성공 여부와
`RdpClient::lastError()`를 이용해 상태 표시, 입력 필드, 버튼 상태를 갱신한다.

Disconnect를 누르면 `RdpClient::disconnect()`를 호출한다. 연결 중에는 주소와
포트 및 Connect 버튼을 비활성화하고 Disconnect 버튼만 활성화하여 중복 연결
요청을 방지한다.

```text
Server address + Port
        |
        v
    MainWindow
        |
        v
RdpClient Wrapper
        |
        v
      FreeRDP
```

## 오류 처리

빈 주소, 범위를 벗어난 포트, FreeRDP 초기화 실패 및 연결 실패는 Wrapper가
제공하는 오류 문자열로 표시한다. 오류는 다음 세 위치에서 확인할 수 있다.

- Connection failed 상태
- 상태 표시줄의 상세 오류
- RDP Connection Error 대화상자

Wrapper가 초기화되지 않은 경우 연결 입력과 버튼은 비활성화된다.

## Remote Desktop 영역

`remoteDesktopView`는 현재 연결 전/연결 중/연결 후 안내 문구를 표시하는
확장 가능한 프레임이다. 실제 Framebuffer 수신과 화면 렌더링은 후속 티켓의
범위이며, 해당 구현이 이 프레임을 출력 대상으로 확장할 수 있다.
