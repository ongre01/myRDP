# RDP-006 Keyboard / Mouse 입력 전달 구현

## 구현 결과

`RDPClient`의 원격 화면 Widget에서 발생한 키보드와 마우스 이벤트를
FreeRDP 입력 API로 전달하는 경로를 구현했다.

- Key press/release 및 자동 반복 전달
- Windows 일반/확장 스캔코드 변환
- Pause 키 전용 RDP 입력 시퀀스 처리
- Mouse move 및 좌/우 버튼 press/release 전달
- 세로 Mouse wheel 전달
- 비율 유지 렌더링 영역을 기준으로 한 원격 Desktop 좌표 변환
- 레터박스 영역 입력 제외 및 drag 중 화면 이탈 좌표 clamp
- 포커스 상실 시 눌린 키와 버튼 release 처리

## 계층 구성

Qt 이벤트 수집, RDP 입력 표현, FreeRDP 전송을 다음과 같이 분리했다.

```text
RemoteDesktopWidget
  |
  | QKeyEvent / QMouseEvent / QWheelEvent
  v
InputEventTranslator
  |
  | RdpKeyboardInput / RdpPointerInput
  v
MainWindow
  |
  v
RdpClient
  |
  | freerdp_input_send_keyboard_event_ex
  | freerdp_input_send_keyboard_pause_event
  | freerdp_input_send_mouse_event
  v
RDP Server
```

`RemoteDesktopWidget`은 Qt 이벤트의 수집과 현재 화면 영역을 알고 있으며,
`InputEventTranslator`는 Qt 전용 이벤트를 연결 수명주기와 분리된 RDP 입력 모델로
변환한다. `RdpClient`만 FreeRDP 입력 flag와 전송 함수를 사용한다.

## Keyboard 처리

Windows에서 Qt 6의 `nativeScanCode()`가 제공하는 scan code의 하위 바이트를 사용하고,
`0xE000` prefix가 있는 키는 RDP extended scan code로 변환한다. 따라서 방향키,
오른쪽 Ctrl/Alt, Insert/Delete, 숫자 키패드 Enter처럼 일반 키와 scan code가 겹치는
확장 키를 구분한다.

Qt가 자동 반복 과정에서 생성하는 중간 KeyRelease는 전송하지 않고 repeat KeyPress와
마지막 실제 KeyRelease만 전달한다. Pause는 일반 scan code press/release가 아니라
FreeRDP의 pause 전용 전송 함수를 사용한다.

원격 화면이 포커스를 잃으면 Widget이 기록한 눌린 scan code를 release한다. 이로써
Alt+Tab이나 다른 Widget으로의 포커스 이동 후 원격 세션에 modifier가 눌린 상태로
남는 문제를 방지한다. 연결되지 않았거나 아직 framebuffer가 없는 상태에서는 입력을
전송하지 않는다.

## Mouse와 좌표 변환

`RemoteDesktopWidget`이 그리는 실제 Desktop 사각형은 원본 종횡비를 유지하므로
Widget 전체 크기와 일치하지 않을 수 있다. 입력 좌표는 다음 기준으로 변환한다.

```text
remoteX = floor((widgetX - renderedLeft) / renderedWidth  * desktopWidth)
remoteY = floor((widgetY - renderedTop)  / renderedHeight * desktopHeight)
```

변환 결과는 `(0, 0)`부터 `(desktopWidth - 1, desktopHeight - 1)`까지로 제한한다.
일반 이동, 버튼 press, wheel이 렌더링 영역 밖에서 발생하면 전송하지 않는다. 다만
원격 화면 안에서 누른 버튼을 drag한 채 밖으로 이동한 경우에는 좌표를 가장자리로
제한하고 move/release를 계속 전송하여 원격 버튼이 눌린 상태로 남지 않게 한다.

Wheel delta는 RDP pointer event의 9-bit wheel 값에 맞게 최대 255 단위로 나누어
전송하며 음수 값은 `PTR_FLAGS_WHEEL_NEGATIVE`와 2의 보수 형식으로 인코딩한다.

## 오류 처리

`RdpClient`는 활성 연결과 FreeRDP input context를 확인한 뒤 입력을 보낸다. 좌표가
RDP의 16-bit 범위를 벗어나거나 FreeRDP 전송 함수가 실패하면 오류 문자열을 설정하고,
`MainWindow`가 event timer와 연결을 종료한 후 기존 연결 오류 UI로 전달한다.

## 검증

Qt 6.11.0 MSVC 2022 64-bit와 저장소의 FreeRDP build를 사용해 다음을 확인했다.

- Debug 빌드 성공
- Release 빌드 성공
- 입력 변환 및 Widget offscreen test 6개 통과
  - 일반/확장 키와 Pause 변환
  - 자동 반복 KeyRelease 제외
  - Desktop 중앙, 경계, 영역 밖, clamp 좌표 변환
  - 좌/우 버튼과 wheel 입력 모델 변환
  - Widget mouse move 전달과 레터박스 제외
  - 포커스 상실 시 눌린 키 release
- Debug/Release 실행 파일 offscreen startup smoke test
- `git diff --check` 통과

FreeRDP/WinPR public header의 기존 deprecated 선언 warning은 출력되지만 이번 변경에서
추가된 warning이나 build error는 없다.

접속 가능한 RDP Server 자격 증명과 대화형 원격 세션이 제공되지 않아 실제 Windows
Desktop에서의 키보드, 마우스, wheel 동작은 이번 자동 검증에 포함하지 않았다.
