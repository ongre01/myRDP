# RDP-014 — 자체 Client ↔ Server 통합 검증

**Priority:** P0  
**Dependencies:** RDP-013

## 목표

자체 개발한 RDPClient와 RDPServer를 연결하여 전체 기능을 검증한다.

## 구성

```text
QtRdp Client
     │
     │ RDP
     ▼
QtRdp Server
```

## 검증 항목

- 연결
- 인증
- Desktop Capture
- 화면 갱신
- Keyboard
- Mouse
- Clipboard
- 연결 종료
- 재연결

## 완료 조건

QtRdp Client와 QtRdp Server만으로 기본적인 원격 Desktop 제어가 가능하다.
