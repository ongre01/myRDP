# RDP-015 — Server 설정 및 Logging 구현

**Priority:** P1  
**Dependencies:** RDP-014

## 목표

RDPServer의 설정 및 문제 분석 기능을 구현한다.

## 설정 항목

```text
Listen Address
RDP Port
Authentication
Certificate
Capture
Maximum Client Count
Log Level
```

## Logging

다음 항목을 기록한다.

```text
Server Start / Stop
Client Connect / Disconnect
Session State
Authentication Result
Desktop Capture Error
RDP Protocol Error
Network Error
```

## 완료 조건

- 설정 파일에서 Server 설정을 읽을 수 있다.
- 잘못된 설정을 검증한다.
- 주요 Server 이벤트가 로그에 기록된다.
- Log Level을 설정할 수 있다.
