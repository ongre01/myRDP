# RDP-006 — Keyboard / Mouse 입력 전달 구현

**Priority:** P0  
**Dependencies:** RDP-005

## 목표

Qt에서 발생한 사용자 입력을 RDP Server로 전달한다.

## 구현 범위

### Keyboard

- Key Press
- Key Release

### Mouse

- Mouse Move
- Left/Right Button
- Button Press/Release
- Mouse Wheel

Qt 입력 이벤트와 RDP 입력 이벤트를 변환하는 계층을 분리한다.

## 완료 조건

- 원격 Windows에서 Keyboard 입력이 동작한다.
- Mouse 이동이 동작한다.
- Mouse Button이 동작한다.
- Mouse Wheel이 동작한다.
- Client Window 내부 좌표가 Remote Desktop 좌표로 정상 변환된다.
