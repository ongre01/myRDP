# RDP-012 — Server 원격 Keyboard / Mouse 입력 처리

**Priority:** P0  
**Dependencies:** RDP-011

## 목표

RDP Client에서 수신한 입력을 Windows 로컬 시스템에 적용한다.

## Platform Interface

```text
InputController
      │
      └── WindowsInputController
```

## 구현 범위

- Keyboard
- Mouse Move
- Mouse Button
- Mouse Wheel

## 완료 조건

- RDP Client에서 Keyboard를 입력하면 Server Windows에 전달된다.
- Mouse Move가 동작한다.
- Mouse Button이 동작한다.
- Mouse Wheel이 동작한다.
- Platform 종속 구현이 Application Layer와 분리되어 있다.
