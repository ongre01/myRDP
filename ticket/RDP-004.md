# RDP-004 — Windows 기본 RDP Server 연결 구현

**Priority:** P0  
**Dependencies:** RDP-003

## 목표

QtRdp Client를 Windows 기본 Remote Desktop Server에 연결한다.

## 구현 범위

- FreeRDP Connection 설정
- RDP Negotiation
- Server 연결
- 인증 처리
- 연결 실패 처리
- 연결 종료 처리

## 검증 구성

```text
QtRdp Client
Qt + FreeRDP
      │
      │ RDP
      ▼
Windows Remote Desktop Server
```

## 완료 조건

- Windows Remote Desktop Server에 연결할 수 있다.
- 정상 계정으로 인증할 수 있다.
- 잘못된 Server 주소를 처리할 수 있다.
- 인증 실패를 처리할 수 있다.
- 정상적으로 연결을 종료할 수 있다.
