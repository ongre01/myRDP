# RDP-009 — RDP Server Test Frame 전송 구현

**Priority:** P0  
**Dependencies:** RDP-008

## 목표

Desktop Capture 구현 전에 FreeRDP Server 화면 전송 기능 자체를 검증한다.

## 구성

```text
RDP Client
    │
    ▼
FreeRDP Server
    │
    ▼
Test Pattern
```

## 구현 범위

실제 Desktop 대신 다음과 같은 테스트 화면을 생성한다.

```text
Solid Color
Color Pattern
Grid
Frame Counter
```

Frame 내용은 구현 편의를 위해 선택할 수 있다.

## 완료 조건

- Client가 Server에 연결된다.
- Server가 Test Frame을 전송한다.
- Client 화면에 Test Frame이 표시된다.
- Frame 내용을 변경하면 Client 화면에 반영된다.
- 반복적인 화면 갱신이 가능하다.
