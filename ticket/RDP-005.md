# RDP-005 — Remote Desktop 화면 출력 구현

**Priority:** P0  
**Dependencies:** RDP-004

## 목표

FreeRDP에서 수신한 Desktop 화면을 Qt Widget에 출력한다.

## 구현 범위

- FreeRDP Framebuffer 처리
- Desktop 해상도 처리
- 화면 갱신
- 변경 영역 처리
- Qt Widget Rendering
- Client Window 크기 변경 대응

화면 데이터 처리와 Qt UI Rendering 코드는 가능한 한 분리한다.

## 완료 조건

- Windows Remote Desktop 화면이 Qt Widget에 표시된다.
- 원격 화면 변경이 Client 화면에 반영된다.
- 화면 해상도를 올바르게 처리한다.
- Client Window 크기 변경 시 화면이 정상 표시된다.
- 연결 종료 후 화면 리소스가 정상 해제된다.
