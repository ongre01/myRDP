# RDP-008 — FreeRDP Server 최소 구조 구현

**Priority:** P0  
**Dependencies:** RDP-007

## 목표

FreeRDP Server API를 Wrapping하는 Server Architecture를 구현한다.

## 구조

```text
Qt UI / Application
        │
        ▼
RDP Server Wrapper
        │
        ▼
FreeRDP Server
```

Server Session은 향후 복수 Client를 지원할 수 있도록 별도의 객체로 분리한다.

```text
RdpServer
 ├── Session 1
 ├── Session 2
 └── ...
```

초기 버전에서는 Session 1개만 지원해도 된다.

## 구현 범위

- Server 초기화
- Listen
- Client 연결 수락
- Session 생성
- Client Disconnect 처리
- Server 종료

## 완료 조건

- RDPServer 애플리케이션이 실행된다.
- 지정한 Port에서 Client 연결을 기다릴 수 있다.
- Client 연결 이벤트를 감지할 수 있다.
- Client 종료를 감지할 수 있다.
- Server를 정상적으로 종료할 수 있다.
