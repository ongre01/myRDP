# RDP-016 — Server 백그라운드 실행 및 자동 시작 구조 구현

**Priority:** P1  
**Dependencies:** RDP-015

## 목표

RDPServer가 일반 사용 시 UI 노출 없이 백그라운드에서 동작할 수 있도록 한다.

## 구현 범위

- Background 실행
- 최소 GUI
- Server 상태 확인
- Start/Stop 상태 관리
- 시스템 시작 시 자동 실행 가능한 구조

## 완료 조건

- GUI를 계속 표시하지 않고 Server가 동작한다.
- Server 실행 상태를 확인할 수 있다.
- 필요한 경우 설정 화면을 표시할 수 있다.
- Windows 시작 시 자동 실행할 수 있는 구조를 제공한다.
