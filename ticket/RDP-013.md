# RDP-013 — Server Clipboard 동기화 구현

**Priority:** P0  
**Dependencies:** RDP-012

## 목표

QtRdp Server의 Text Clipboard 연동을 구현한다.

## 지원 방향

```text
Client → Server
Server → Client
```

## 완료 조건

- Client Clipboard Text를 Server에서 사용할 수 있다.
- Server Clipboard Text를 Client에서 사용할 수 있다.
- Clipboard 처리가 Platform Layer와 분리되어 있다.
