# RDP-017 — Windows 1차 Release 통합 테스트

**Priority:** P0  
**Dependencies:** RDP-016

## 목표

Windows 1차 개발 완료 기준을 검증한다.

## Client 검증

```text
Qt Widgets Client 실행
Windows 기본 RDP Server 연결
Desktop 화면 표시
Keyboard
Mouse
Text Clipboard
```

## Server 검증

```text
Server 실행
Client 연결 대기
Windows 기본 RDP Client 연결
Desktop 화면 전송
Keyboard / Mouse
Client Connect / Disconnect
Background 실행
```

```text
QtRdp Client

```

```text
Windows RDP Client
      ↓
QtRdp Server
```

이 티켓 완료 이후 macOS 개발을 시작한다.
