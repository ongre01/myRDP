# RDP-007 — Text Clipboard 연동 구현

**Priority:** P0  
**Dependencies:** RDP-006

## 목표

Client와 RDP Server 사이에서 Text Clipboard 동기화를 지원한다.

## 지원 방향

```text
Client → Server
Server → Client
```

## 구현 범위

초기 버전에서는 Text Clipboard만 지원한다.

파일 및 이미지 Clipboard는 범위에 포함하지 않는다.

## 완료 조건

- Client에서 복사한 Text를 원격 Windows에서 붙여넣을 수 있다.
- 원격 Windows에서 복사한 Text를 Client에서 붙여넣을 수 있다.
- 빈 Clipboard를 안전하게 처리한다.
- 연결 종료 시 Clipboard 관련 리소스를 정상 해제한다.
