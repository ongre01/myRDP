# RDP-003 — Windows RDP Client 최소 UI 구현

**Priority:** P0  
**Dependencies:** RDP-002

## 목표

Windows에서 실행 가능한 최소 RDP Client GUI를 구현한다.

## UI 구성

```text
Server Address
Port
Connect
Disconnect
Connection Status
Remote Desktop View
```

## 구현 범위

- Server 주소 입력
- Port 입력
- Connect 버튼
- Disconnect 버튼
- 연결 상태 표시
- 오류 메시지 표시
- Remote Desktop 표시 영역

## 완료 조건

- Windows에서 RDPClient가 실행된다.
- Server 주소와 Port를 입력할 수 있다.
- Connect/Disconnect 동작이 Wrapper에 전달된다.
- 연결 상태를 GUI에서 확인할 수 있다.
- 연결 실패 시 사용자에게 오류를 표시한다.
