# RDP-002 — FreeRDP Client Wrapper 구현

**Priority:** P0  
**Dependencies:** RDP-001

## 목표

Qt UI와 FreeRDP Client API 사이의 Wrapper Layer를 구현한다.

## 구조

```text
Qt UI
  │
  ▼
Application Layer
  │
  ▼
FreeRDP Client Wrapper
  │
  ▼
FreeRDP
```

## 구현 범위

예상 인터페이스:

```cpp
class RdpClient
{
public:
    bool connectToServer(const ConnectionInfo& info);
    void disconnect();

    bool isConnected() const;
};
```

필요한 FreeRDP Context 및 Instance의 생성/해제를 Wrapper 내부에서 관리한다.

## 완료 조건

- Qt 코드에서 FreeRDP 내부 객체를 직접 관리하지 않는다.
- Wrapper를 통해 FreeRDP 초기화가 가능하다.
- Wrapper를 통해 연결/종료 요청이 가능하다.
- FreeRDP 초기화 실패가 Application Layer에 전달된다.
- 객체 종료 시 FreeRDP 관련 리소스가 정상 해제된다.
