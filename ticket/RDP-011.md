# RDP-011 — Windows Desktop Capture Platform Layer 구현

**Priority:** P0  
**Dependencies:** RDP-010

## 목표

Windows Desktop 화면을 Capture하여 RDP Server로 전달한다.

## 구조

```text
Windows Desktop
       │
       ▼
DesktopCapture Interface
       │
       ▼
WindowsDesktopCapture
       │
       ▼
RDP Server
```

Application Layer에서는 Windows API를 직접 호출하지 않는다.

## 구현 범위

- Desktop 해상도 조회
- Desktop Capture
- Frame Buffer 생성
- 변경 영역 처리
- Capture Error 처리

## 완료 조건

- Windows Desktop 화면을 Capture할 수 있다.
- Capture된 화면을 RDP Client에 표시할 수 있다.
- Desktop 해상도 변경을 처리할 수 있다.
- Capture 실패가 Server에 전달된다.
- 불필요한 전체 화면 전송을 줄일 수 있는 구조를 가진다.
