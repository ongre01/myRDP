# RDP-010 — Windows 기본 RDP Client 호환성 검증

**Priority:** P0  
**Dependencies:** RDP-009

## 목표

Windows 기본 Remote Desktop Client가 QtRdp Server에 접속할 수 있도록 한다.

## 검증 구성

```text
Windows Remote Desktop Client
            │
            │ RDP
            ▼
        QtRdp Server
        Qt + FreeRDP
```

## 검증 범위

- Connection
- RDP Negotiation
- TLS
- Desktop 화면
- 연결 종료
- 재연결

## 완료 조건

- Windows 기본 Remote Desktop Client가 Server에 연결된다.
- Test Frame이 Windows Remote Desktop Client에 표시된다.
- 연결 종료가 정상 처리된다.
- 재연결할 수 있다.
